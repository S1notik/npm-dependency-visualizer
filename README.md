# npm-dependency-visualizer

Консольный инструмент для анализа и визуализации графа зависимостей
npm-пакетов.

Приложение получает данные о пакетах из npm-репозитория, строит граф
прямых и транзитивных зависимостей, определяет порядок их загрузки
и формирует визуализацию.

## Требования

- JDK 17 или новее;
- Maven 3;
- Bash для запуска через `run.sh`;
- подключение к интернету для работы с удалённым npm-репозиторием.

## Сборка и запуск

Сборка проекта:

```bash
mvn clean package
```

Запуск с конфигурацией по умолчанию:

```bash
./run.sh
```

Запуск с указанным файлом конфигурации:

```bash
./run.sh config/example.csv
```

По умолчанию приложение использует файл `config/example.csv`.

## Конфигурация

Параметры приложения задаются в CSV-файле в кодировке UTF-8.

```csv
packageName,repository,testMode,asciiTree
lodash,https://registry.npmjs.org,false,true
```

| Параметр | Описание |
| --- | --- |
| `packageName` | Имя анализируемого пакета |
| `repository` | URL npm-репозитория или путь к файлу тестового репозитория |
| `testMode` | Режим работы с тестовым репозиторием: `true` или `false` |
| `asciiTree` | Вывод зависимостей в виде ASCII-дерева: `true` или `false` |

Файл должен содержать четыре обязательных заголовка и одну запись
настроек. Порядок столбцов может быть любым. Пустые строки игнорируются.

При `testMode=false` параметр `repository` содержит HTTP- или HTTPS-адрес
репозитория. При `testMode=true` он содержит путь к локальному файлу
тестового репозитория.

Относительные пути при запуске через `run.sh` определяются от корня проекта.

## Анализ зависимостей

Приложение получает сведения о пакете из указанного npm-репозитория
и извлекает информацию о его прямых зависимостях.

Для построения полного графа анализируются также зависимости найденных
пакетов. Обход выполняется алгоритмом DFS без рекурсии. Циклические
зависимости обрабатываются без бесконечного обхода.

## Тестовый репозиторий

Тестовый режим позволяет анализировать локальное описание графа
без обращения к удалённому npm-репозиторию.

Чтобы включить режим, укажите `testMode=true` и путь к файлу репозитория
в параметре `repository`. Имена пакетов в тестовом репозитории задаются
большими латинскими буквами.

## Порядок загрузки

На основе графа зависимостей приложение определяет порядок загрузки
пакетов: зависимость располагается перед пакетом, который её использует.

Результат сравнивается с работой npm. Возможные расхождения зависят
от разрешения версий, особенностей установки и обработки зависимостей
менеджером пакетов.

## Визуализация

Граф представляется на языке диаграмм Mermaid и отображается
в графическом виде.

Если параметр `asciiTree` равен `true`, зависимости дополнительно
выводятся в консоль в виде ASCII-дерева:

```text
A
|-- B
|   `-- D
`-- C
```

В графе с общими или циклическими зависимостями текстовое дерево
представляет результат обхода графа.

## Обработка ошибок

Приложение сообщает об ошибках конфигурации, чтения файлов
и получения данных из репозитория.

Сообщения об ошибках выводятся в стандартный поток ошибок.
При успешном завершении возвращается код `0`, при ошибке — `1`.

## Тестирование

Запуск автоматических тестов:

```bash
mvn test
```

Сборка с полной проверкой:

```bash
mvn clean verify
```

## Используемые технологии

- **Java** — реализация приложения.
- **Maven** — сборка и управление зависимостями.
- **Apache Commons CSV** — чтение конфигурации.
- **JUnit Jupiter** — автоматическое тестирование.
- **Mermaid** — текстовое представление графа зависимостей.

Информация о зависимостях пакетов получается без использования готовых
менеджеров пакетов и специализированных библиотек для получения зависимостей.
