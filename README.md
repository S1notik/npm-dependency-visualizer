# npm-dependency-visualizer

Учебный Java CLI-проект, вариант 20. Реализован этап 1: чтение CSV-конфигурации,
проверка ошибок и вывод всех настроек в формате ключ=значение.
Получение зависимостей и визуализация относятся к следующим этапам.

## Требования и сборка

Нужны JDK 17 или новее и Maven 3. При первой сборке нужен интернет для загрузки
библиотек и плагинов. Maven использует Apache Commons CSV для чтения CSV
и JUnit для тестов. Библиотеки для получения зависимостей npm не используются.

```sh
mvn clean verify
./run.sh
./run.sh config/example.csv
```

Скрипт собирает проект и запускает Main. Без аргументов используется
config/example.csv. Единственный аргумент — путь к конфигурации.
Относительные пути при запуске через run.sh считаются от корня проекта.
При прямом запуске Main — от рабочей папки процесса.

## Конфигурация

Файл в UTF-8:

```csv
packageName,repository,testMode,asciiTree
lodash,https://registry.npmjs.org,false,true
```

- packageName: непустое имя пакета без пробельных символов. Полная проверка
  правил npm-имён пока не выполняется; тестовые имена A, B также допустимы.
- repository: HTTP/HTTPS URL с хостом при testMode=false; путь к существующему
  доступному для чтения обычному файлу при testMode=true.
- testMode: строго true или false; выбирает реальный или тестовый источник.
- asciiTree: строго true или false; настройка будущего вывода дерева.

Заголовки обязательны, регистр важен, порядок столбцов свободный.
Допускается ровно одна запись настроек. Пустые строки игнорируются.
Пробелы по краям значений удаляются. Поддерживаются кавычки, запятые и переносы
строк внутри кавычек по правилам CSV; кавычка внутри поля записывается как "".
Сеть на первом этапе не проверяется, содержимое тестового репозитория не разбирается.

Результат успешного запуска:

```text
packageName=lodash
repository=https://registry.npmjs.org
testMode=false
asciiTree=true
```

## Ошибки и тесты

```sh
mvn test
./run.sh config/missing.csv
```

Ошибки выводятся в stderr, код завершения — 1. При успехе — 0.
Для демонстрации проверок можно в копии example.csv очистить любое поле,
заменить переключатель на yes, URL на not-a-url, повторить/удалить заголовок,
добавить вторую запись или включить testMode с несуществующим путём.
Каждый такой запуск должен завершаться понятным сообщением об ошибке.

Автотесты в tests проверяют успешное чтение и вывод, порядок столбцов,
пустые строки, кавычки и запятые в пути, ошибки заголовков и записей,
каждый параметр, повреждённый CSV, отсутствие файла и коды завершения.

## Структура

- src/main/java/dev/npmvisualizer/Main.java — запуск и вывод ошибок/настроек.
- config/AppConfig (в Java-пакете) — неизменяемый объект настроек.
- config/CsvConfigReader (в Java-пакете) — чтение и проверка CSV.
- config/example.csv — пример пользовательской конфигурации.
- tests — автоматические тесты.
- run.sh — сборка и запуск через Maven.

Артефакты target/, файлы IntelliJ и JAR-файлы в Git не добавляются.
